# BrokerLord Directory

A fast, curated web directory of free tools, AI resources, and useful websites built with **VitePress**.

## Features

- **Light / Dark / AMOLED Display Mode Toggle** – 1-click mode switcher in the navbar plus a theme popover with live accent color palettes.
- **Category Sidebar** – Color-coded icon sidebar organizing curated directory categories, Beginners Guide, and Monthly Updates.
- **Instant Local Search** – Powered by VitePress MiniSearch with fuzzy matching, detailed previews, and `/` or `Ctrl + K` keyboard shortcuts.
- **Homepage Category Grid** – Responsive card grid with group filter pills (`All`, `Privacy, AI & Web`, `Media & Reading`, `Apps & OS`).
- **Curated Highlights** – Starred top picks, inline `FOSS` / `Privacy` / `Web` badges, right-hand table of contents, and interactive page feedback widget.

## Commands

```bash
# Install dependencies
npm install

# Start live development server
npm run dev

# Build static production site (outputs to docs/.vitepress/dist)
npm run build

# Preview built static site locally
npm run preview
```
