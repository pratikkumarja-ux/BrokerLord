# Linux / macOS

<p class="bl-page-lead">The <code>$HOME</code> of Linux distributions, macOS open-source enhancers, package managers, and modern terminal tools.</p>

## Linux Distributions & Wikis

- <span class="bl-star">★ Top Pick</span> **[Arch Wiki](https://wiki.archlinux.org/)** — The gold standard of technical Linux documentation, useful across every distribution. <TagBadge type="web">Web</TagBadge>
- **[Fedora Workstation](https://fedoraproject.org/)** — Polished, cutting-edge yet reliable Linux desktop backed by strong open-source engineering. <TagBadge type="foss">FOSS</TagBadge>
- **[Linux Mint](https://linuxmint.com/)** — Friendly, rock-solid desktop distribution ideal for newcomers switching from Windows. <TagBadge type="foss">FOSS</TagBadge>
- **[Bazzite](https://bazzite.gg/)** — Immutable, gaming-ready Fedora Atomic image optimized for desktops, HTPCs, and handheld PCs. <TagBadge type="foss">FOSS</TagBadge>

## Linux Package Managers & Desktop Tools

- <span class="bl-star">★ Top Pick</span> **[Flathub (Flatpak)](https://flathub.org/)** — Universal Linux app store delivering sandboxed desktop applications across any distro. <TagBadge type="foss">FOSS</TagBadge>
- **[Distrobox](https://distrobox.it/)** — Run any Linux distribution seamlessly inside your terminal with full access to your home directory. <TagBadge type="foss">FOSS</TagBadge>
- **[Timeshift](https://github.com/linuxmint/timeshift)** — System restore snapshots using RSYNC or BTRFS so you can roll back updates safely. <TagBadge type="foss">FOSS</TagBadge>

## macOS Essentials & Open-Source Enhancers

- <span class="bl-star">★ Top Pick</span> **[Homebrew](https://brew.sh/)** — The missing package manager for macOS (and Linux) to install CLI tools and GUI casks cleanly. <TagBadge type="foss">FOSS</TagBadge>
- **[Raycast](https://www.raycast.com/)** — Blazing-fast launcher, clipboard history, window manager, and extensible command palette with a rich free tier.
- **[Rectangle](https://rectangleapp.com/)** — Lightweight, open-source keyboard window snapping for macOS. <TagBadge type="foss">FOSS</TagBadge>
- **[Stats](https://github.com/exelban/stats)** — Open-source macOS menu bar system monitor for CPU, GPU, RAM, network, and battery. <TagBadge type="foss">FOSS</TagBadge>
- **[IINA](https://iina.io/)** — Modern, native macOS media player powered by `mpv` with Picture-in-Picture and touch gesture support. <TagBadge type="foss">FOSS</TagBadge>
- **[Maccy](https://maccy.app/)** — Lightweight, keyboard-first open-source clipboard manager for macOS. <TagBadge type="foss">FOSS</TagBadge>

## Cross-Platform Terminal & CLI Gems

- **[Ghostty](https://ghostty.org/)** — Fast, native, GPU-accelerated open-source terminal emulator for macOS and Linux. <TagBadge type="foss">FOSS</TagBadge>
- **[Starship](https://starship.rs/)** — Minimal, blazing-fast, infinitely customizable prompt for Bash, Zsh, Fish, and PowerShell. <TagBadge type="foss">FOSS</TagBadge>
- **[ripgrep (rg)](https://github.com/BurntSushi/ripgrep)** — Ultra-fast recursive regex code search tool that respects `.gitignore`. <TagBadge type="foss">FOSS</TagBadge>
- **[fzf](https://github.com/junegunn/fzf)** — General-purpose command-line fuzzy finder for files, history, and git branches. <TagBadge type="foss">FOSS</TagBadge>
