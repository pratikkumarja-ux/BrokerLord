# Adblocking / Privacy

<p class="bl-page-lead">Block ads, strip trackers, harden your browser, and take back control of your digital footprint.</p>

## Adblocking

- <span class="bl-star">★ Top Pick</span> **[uBlock Origin](https://ublockorigin.com/)** — Efficient, open-source content blocker for Firefox, Chromium, and mobile Firefox. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>
- **[Pi-hole](https://pi-hole.net/)** — Network-wide DNS sinkhole that blocks ads and telemetry across every device on your LAN. <TagBadge type="foss">FOSS</TagBadge>
- **[AdGuard Home](https://adguard.com/en/adguard-home/overview.html)** — Self-hosted network-wide ad and tracker blocking DNS server with a clean web UI. <TagBadge type="foss">FOSS</TagBadge>
- **[SponsorBlock](https://sponsor.ajay.app/)** — Community-powered extension that automatically skips sponsored reads and intros on YouTube. <TagBadge type="foss">FOSS</TagBadge>
- **[Consent-O-Matic](https://consentomatic.au.dk/)** — Automatically rejects intrusive GDPR cookie consent banners in the background. <TagBadge type="foss">FOSS</TagBadge>

## DNS Resolvers

- <span class="bl-star">★ Top Pick</span> **[Quad9](https://www.quad9.net/)** — Non-profit encrypted DNS resolver that blocks malicious domains and never logs IP addresses. <TagBadge type="privacy">Privacy</TagBadge>
- **[Mullvad DNS](https://mullvad.net/en/help/dns-over-https-and-dns-over-tls)** — Public, no-logs DoH/DoT resolvers with optional ad, tracker, and malware blocklists. <TagBadge type="privacy">Privacy</TagBadge>
- **[NextDNS](https://nextdns.io/)** — Customizable cloud DNS firewall with generous free tier and per-device analytics. <TagBadge type="web">Web</TagBadge>
- **[Control D Free DNS](https://controld.com/free-dns)** — Fast public DNS endpoints with optional malware and ad-blocking profiles.

## Privacy-Focused Browsers

- <span class="bl-star">★ Top Pick</span> **[Firefox](https://www.mozilla.org/firefox/)** — Open-source browser supporting full Manifest V2 content blockers like uBlock Origin. <TagBadge type="foss">FOSS</TagBadge>
- **[LibreWolf](https://librewolf.net/)** — Community-maintained Firefox fork hardened for privacy and security out of the box. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>
- **[Brave](https://brave.com/)** — Chromium browser with native ad-blocking shields, fingerprint protection, and clean defaults.
- **[Tor Browser](https://www.torproject.org/)** — Multi-hop onion routing browser for strong anonymity and anti-fingerprinting. <TagBadge type="foss">FOSS</TagBadge>

## Password Managers & 2FA
