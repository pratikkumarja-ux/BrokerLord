# Developer & Internet Tools

<p class="bl-page-lead">Zero-install web utilities, browser extensions, developer documentation hubs, and self-hosted open-source stacks.</p>

## Web Utilities

- <span class="bl-star">★ Top Pick</span> **[CyberChef](https://gchq.github.io/CyberChef/)** — The Cyber Swiss Army Knife for encoding, Base64, hashing, regex, compression, and data analysis right in your browser. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="web">Web</TagBadge>
- <span class="bl-star">★ Top Pick</span> **[IT-Tools](https://it-tools.tech/)** — Clean, open-source collection of 70+ handy web utilities for developers, sysadmins, and everyday formatting. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="web">Web</TagBadge>
- **[Photopea](https://www.photopea.com/)** — Advanced in-browser image editor supporting PSD, XCF, Sketch, XD, and RAW layers with zero installation. <TagBadge type="web">Web</TagBadge>
- **[Squoosh](https://squoosh.app/)** — Client-side image compression and format conversion (WebP, AVIF, MozJPEG) powered by WebAssembly. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="web">Web</TagBadge>
- **[Stirling-PDF](https://github.com/Stirling-Tools/Stirling-PDF)** — Self-hosted, open-source local PDF toolbox for merging, splitting, OCR, and redaction. <TagBadge type="foss">FOSS</TagBadge>
- **[PairDrop](https://pairdrop.net/)** — Open-source peer-to-peer local and internet file sharing right in the browser with no sign-up. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="web">Web</TagBadge>

## Diagramming & Whiteboards

- <span class="bl-star">★ Top Pick</span> **[Excalidraw](https://excalidraw.com/)** — Fast, open-source hand-drawn virtual whiteboard with end-to-end encrypted live collaboration. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="web">Web</TagBadge>
- **[diagrams.net (draw.io)](https://app.diagrams.net/)** — Feature-complete open-source flowchart, architecture, and UML diagramming tool. <TagBadge type="foss">FOSS</TagBadge>
- **[Mermaid Live Editor](https://mermaid.live/)** — Turn concise Markdown-like text syntax into crisp flowcharts, sequence diagrams, and ERDs. <TagBadge type="foss">FOSS</TagBadge>

## Developer References & Sandboxes

- <span class="bl-star">★ Top Pick</span> **[DevDocs](https://devdocs.io/)** — Unified, ultra-fast offline-capable API documentation viewer across 100+ languages and frameworks. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="web">Web</TagBadge>
- **[MDN Web Docs](https://developer.mozilla.org/)** — Authoritative reference and learning hub for HTML, CSS, JavaScript, and Web APIs.
- **[Regex101](https://regex101.com/)** — Interactive regular expression tester, debugger, and real-time explanation tool. <TagBadge type="web">Web</TagBadge>
- **[Bruno](https://www.usebruno.com/)** — Fast, Git-friendly, open-source offline API client alternative to Postman. <TagBadge type="foss">FOSS</TagBadge>
- **[Hoppscotch](https://hoppscotch.io/)** — Lightweight open-source web-based API development ecosystem supporting REST, GraphQL, and WebSockets. <TagBadge type="foss">FOSS</TagBadge>
