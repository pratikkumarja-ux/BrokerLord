# Free Software & Downloads

<p class="bl-page-lead">Trusted, open-source desktop software covering productivity, creative suites, system utilities, and clean package installers.</p>

## Office & Productivity

- <span class="bl-star">★ Top Pick</span> **[LibreOffice](https://www.libreoffice.org/)** — Complete, open-source office suite (Writer, Calc, Impress) compatible with Microsoft Office formats. <TagBadge type="foss">FOSS</TagBadge>
- **[Obsidian](https://obsidian.md/)** — Fast, local-first Markdown knowledge base and note-taking workspace with graph view and plugins.
- **[Logseq](https://logseq.com/)** — Privacy-first, open-source outliner and personal knowledge management tool. <TagBadge type="foss">FOSS</TagBadge>
- **[Zotero](https://www.zotero.org/)** — Open-source research assistant for collecting, citing, and organizing PDFs and bibliographies. <TagBadge type="foss">FOSS</TagBadge>
- **[SumatraPDF](https://www.sumatrapdfreader.org/)** — Blazing-fast, lightweight open-source PDF, EPUB, and comic reader for Windows. <TagBadge type="foss">FOSS</TagBadge>

## Design, 3D & Image Editing

- <span class="bl-star">★ Top Pick</span> **[Blender](https://www.blender.org/)** — Studio-grade open-source 3D modeling, sculpting, animation, VFX, and rendering suite. <TagBadge type="foss">FOSS</TagBadge>
- **[GIMP](https://www.gimp.org/)** — Cross-platform open-source raster image editor and photo manipulation powerhouse. <TagBadge type="foss">FOSS</TagBadge>
- **[Inkscape](https://inkscape.org/)** — Professional open-source vector graphics editor (SVG, illustrations, logos, diagrams). <TagBadge type="foss">FOSS</TagBadge>
- **[Krita](https://krita.org/)** — Open-source digital painting and 2D illustration app built by artists for artists. <TagBadge type="foss">FOSS</TagBadge>
- **[Darktable](https://www.darktable.org/)** — Open-source photography workflow and RAW developer alternative to Lightroom. <TagBadge type="foss">FOSS</TagBadge>

## Essential System Utilities & Installers

- <span class="bl-star">★ Top Pick</span> **[7-Zip](https://www.7-zip.org/)** — Fast, tiny, open-source file archiver supporting 7z, ZIP, RAR, TAR, and strong AES-256 encryption. <TagBadge type="foss">FOSS</TagBadge>
- **[LocalSend](https://localsend.org/)** — Open-source, cross-platform AirDrop alternative for instant LAN file sharing with no internet required. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>
- **[Syncthing](https://syncthing.net/)** — Continuous, decentralized, encrypted peer-to-peer file synchronization across your devices. <TagBadge type="foss">FOSS</TagBadge>
- **[Everything (Voidtools)](https://www.voidtools.com/)** — Instant real-time filename search across millions of files on Windows NTFS drives.
- **[UniGetUI (WingetUI)](https://www.marticliment.com/unigetui/)** — Clean graphical interface to safely install and auto-update apps via Winget, Scoop, and Chocolatey. <TagBadge type="foss">FOSS</TagBadge>
- **[AlternativeTo](https://alternativeto.net/)** — Crowdsourced software discovery site to find free and open-source alternatives to any paid app. <TagBadge type="web">Web</TagBadge>
