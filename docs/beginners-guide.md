## Adblocking

> How important is using an adblocker?

Modern websites are packed with intrusive pop-ups, third-party trackers, and deceptive fake download buttons. A solid content blocker dramatically improves speed, security, and readability.

- <span class="bl-star">★ Top Pick</span> **[uBlock Origin](https://ublockorigin.com/)** — Lightweight, open-source wide-spectrum content blocker for desktop and mobile Firefox. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>
- **[AdGuard DNS](https://adguard-dns.io/)** — System-wide DNS ad & tracker filtering without installing extra software. <TagBadge type="privacy">Privacy</TagBadge>
- **[SponsorBlock](https://sponsor.ajay.app/)** — Crowdsourced browser extension that skips sponsored segments, intros, and reminders on YouTube. <TagBadge type="foss">FOSS</TagBadge>

::: info Avoid Stacking Adblockers
Running two full adblockers (like uBlock Origin and AdGuard Extension) at the same time can cause filter conflicts and break sites. Stick to **uBlock Origin** on its own, optionally paired with specialized extensions like SponsorBlock.
:::

## Safe Downloads & File Scanning

> How can I verify a file or website is safe before running it?

Always download software from the project's official website, GitHub Releases, or a trusted package manager (`winget`, `Homebrew`, `Flatpak`, `F-Droid`). If you are ever unsure about an installer or URL:

- <span class="bl-star">★ Top Pick</span> **[VirusTotal](https://www.virustotal.com/)** — Scan files and URLs across 70+ antivirus engines and community threat feeds. <TagBadge type="web">Web</TagBadge>
- **[Hatching Triage](https://tria.ge/)** — Cloud malware sandbox for inspecting suspicious executables and APKs safely. <TagBadge type="web">Web</TagBadge>
- **[Bitwarden Password Manager](https://bitwarden.com/)** — Open-source, zero-knowledge password vault across all devices. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>

## Recommended Browsers

- <span class="bl-star">★ Top Pick</span> **[Firefox](https://www.mozilla.org/firefox/)** — Independent rendering engine with full uBlock Origin support on both desktop and Android. <TagBadge type="foss">FOSS</TagBadge>
- **[Brave Browser](https://brave.com/)** — Chromium-based browser with strong built-in tracker and ad shielding out of the box. <TagBadge type="privacy">Privacy</TagBadge>
- **[LibreWolf](https://librewolf.net/)** — Privacy-hardened Firefox fork with telemetry stripped and uBlock Origin preinstalled. <TagBadge type="foss">FOSS</TagBadge>
