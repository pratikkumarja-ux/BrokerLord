## Ways to Get Involved

- **Explore the Wiki:** Start with the [Beginners Guide](/beginners-guide) or press `/` to instantly search any topic.
- **Suggest a Resource:** Follow the [Contributing Guide](/other/contributing) to add new open-source projects, fix outdated links, or suggest a new category.
- **Follow Monthly Updates:** Check the [Posts Archive](/posts/) each month for highlights of newly added tools and site features.

## Principles We Follow

- **Zero Tracking:** BrokerLord is a pure static site with zero analytics scripts, zero ad trackers, and zero cookies. Your theme and AMOLED preference stay strictly in your own browser's `localStorage`.
- **Speed First:** Pre-rendered static HTML with instant client-side search.
- **Open Standards:** Built on Markdown + VitePress so anyone can fork, host, or self-archive the entire directory effortlessly.
