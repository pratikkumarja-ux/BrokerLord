# Android / iOS

<p class="bl-page-lead">Open-source app catalogs, privacy-respecting mobile utilities, and ad-free everyday apps for Android and iOS.</p>

## Android FOSS App Stores & Updaters

- <span class="bl-star">★ Top Pick</span> **[F-Droid](https://f-droid.org/)** — Trusted installable catalog of 100% free and open-source Android apps built from source with zero tracking. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>
- <span class="bl-star">★ Top Pick</span> **[Obtainium](https://obtainium.imranr.dev/)** — Install and auto-update open-source Android apps directly from official GitHub, GitLab, and Codeberg releases. <TagBadge type="foss">FOSS</TagBadge>
- **[Droid-ify](https://github.com/Droid-ify/client)** — Modern Material You F-Droid client with fast repository syncing and clean search. <TagBadge type="foss">FOSS</TagBadge>

## Essential Android FOSS Apps

- **[NewPipe](https://newpipe.net/)** — Lightweight, privacy-friendly open-source YouTube frontend with background play and local subscriptions. <TagBadge type="foss">FOSS</TagBadge>
- **[AntennaPod](https://antennapod.org/)** — Clean, open-source, ad-free podcast manager and player with OPML import/export. <TagBadge type="foss">FOSS</TagBadge>
- **[Organic Maps](https://organicmaps.app/)** — Fast, offline, open-source OpenStreetMap navigation for hiking, cycling, and driving with zero telemetry. <TagBadge type="foss">FOSS</TagBadge> <TagBadge type="privacy">Privacy</TagBadge>
- **[Fossify Suite](https://github.com/FossifyOrg)** — Clean, ad-free open-source replacements for Gallery, Calendar, Contacts, File Manager, and Clock. <TagBadge type="foss">FOSS</TagBadge>
- **[KDE Connect](https://kdeconnect.kde.org/)** — Seamless clipboard sync, notifications, file transfers, and remote control between Android/iOS and desktop. <TagBadge type="foss">FOSS</TagBadge>
- **[LocalSend Mobile](https://localsend.org/)** — Instant cross-platform local Wi-Fi file sharing between Android, iOS, Windows, macOS, and Linux. <TagBadge type="foss">FOSS</TagBadge>
